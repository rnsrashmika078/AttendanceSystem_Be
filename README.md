# University Real-Time Attendance Management System

A secure and scalable real-time attendance management system designed for universities. The system enables lecturers to manage attendance sessions and allows students to mark attendance using QR code scanning with OTP verification.

Built with React Vite and Laravel, the platform provides real-time attendance updates, secure authentication, caching, and optimized API performance using modern web technologies.

## Features

- Student and lecturer authentication
- Laravel Sanctum based authentication
- Email verification with OTP
- QR code attendance scanning
- Real-time attendance updates using WebSockets
- Live attendance monitoring
- Redis based caching
- API rate limiting
- Secure REST API communication
- Attendance history management
- Responsive dashboard interface
